The key result

This is controlled separability on one positive and seven deliberately constructed negatives, not a live population estimate. The production gate remains unchanged until provider-backed anchor calibration.

Why the old metric fails

Length overflow was rewarded

The old token proxy caps at 1.0. A padded summary almost three times the known trace length therefore received maximum coverage and quality. Log-symmetric alignment scored it 0.338.

Padding defeats global similarity

Irrelevant fluent text lowers sequence similarity and raises novelty. Contiguous summary 5-gram containment remained 1.0 and exposed the embedded copy.

Length cannot detect corruption

Reordered and corrupted traces both had perfect length alignment. Exact ordered content anchors caught the failures, providing an independent fidelity channel.

Exploratory live feasibility signal

Open-reasoning digit-palindrome task

The fresh Sonnet 5 run answered 62 correctly. Recovery used 2,508 extraction output tokens versus 2,469 billed harvest output tokens. With the frozen lexical proxy, recovery contains 1,206 units versus 377 in the provider summary (3.199× expansion), while summary 5-gram containment is only 0.0161.
